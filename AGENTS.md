# Repository instructions

Read [docs/architecture.md](docs/architecture.md) for the library contract and scope.
Keep v0.1 focused on runtime validation and rendering. Compile-time schema-template checking is deferred.

For README changes, follow [docs/readme-guidance.md](docs/readme-guidance.md), using the Redactable and Type History READMEs as examples.

Before changing source, install the skills declared in [.skillcatalog/skillcatalog.yml](.skillcatalog/skillcatalog.yml).
Read [docs/agent-skills.md](docs/agent-skills.md) for installation and Rust authoring guidance.
Apply each installed skill whenever its description matches the change.

Keep proposals distinct from approved features and implemented behavior.
